# Sistema de Atención al Cliente Automatizado (OpenAI API)

Este proyecto implementa un agente conversacional inteligente para atención al cliente utilizando la API de OpenAI (`gpt-4o-mini`) y el uso de **Function Calling (Tools)** para simular la integración con bases de datos y sistemas externos.

---

## 🚀 Requisitos Previos

* Python 3.9 o superior.
* Una cuenta de OpenAI con una clave API activa (`OPENAI_API_KEY`).
